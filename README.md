# ABMD15 開発プロジェクト README

## 概要

ABMD15は、物流展への出展を目的として開発している**磁気テープ式AGVと部分的な自律走行機能を組み合わせたハイブリッド搬送車**です。

従来機 **ABM15** は、磁気テープ上を走行する方式のため、荷物の置き場や走行ルートに制約がありました。  
ABMD15では、必要な場所だけ磁気テープから外れて自律走行することで、**パレット保管エリアの有効活用**や**より複雑な走行ルートへの対応**を実現します。

---

# 開発の目的

物流現場では、以下のような課題があります。

- AGVが荷物を通路上の決められた場所にしか置けない
- 荷物を1パレットずつ処理する必要があり、人の作業効率が上がらない
- パレット置き場を複数設けるために広いスペースが必要になる
- 磁気テープ式AGVでは、十字路や狭い曲がり角への対応に制約がある
- AMRは自由度が高い一方で、導入コストが高い

ABMD15では、磁気テープ走行を基本としながら、必要な場所だけ自律走行することで、これらの課題を解決します。

---

# ABMD15の主な追加機能

## 1. 磁気テープから外れて通路脇へ荷下ろし

ABMD15は、基本的には磁気テープ上を走行します。

しかし、荷下ろしが必要な場所では磁気テープから一時的に外れ、通路脇のパレット保管エリアまで自律走行します。

### 従来機 ABM15

従来はパレットを磁気テープ上に置く必要がありました。

そのため、

- パレットをどかさないと次のAGVが通過できない
- 複数の荷下ろし場所を作ると広いスペースが必要
- パレット保管エリアを効率的に使用できない

といった課題がありました。

### ABMD15

ABMD15では、

1. 磁気テープ上を走行
2. 荷下ろし地点で磁気テープから離脱
3. 通路脇の保管エリアへ自律走行
4. 荷下ろし後、再び走行ルートへ復帰

することができます。

これにより、**走行ルートを塞がず、パレット保管エリアをより効率的に活用**できます。

---

## 2. 複数パレットをまとめて保管

ABMD15は、1パレットずつ人が処理する従来の運用から、複数パレットを一時的にまとめて保管する運用を可能にします。

例えば、

- 2パレット
- 3パレット
- それ以上の複数パレット

を通路脇に順番に荷下ろしし、人がまとめて処理することができます。

### 効果

- 人が何度も荷物を取りに行く回数を削減
- 作業者がまとめて処理できる
- AGVの走行ルートを塞がない
- パレット保管スペースを効率的に利用できる

**「AGVは搬送を継続し、人は必要なタイミングでまとめて処理する」運用**を実現します。

---

## 3. 空きスペースを自動で探して荷下ろし

ABMD15は、パレット保管エリア内の空きスペースを検知し、荷下ろし可能な場所を自動で探すことを目指しています。

パレットがすでに置かれている場合でも、空いている場所を判断し、その位置へ荷下ろしします。

### 期待される効果

- 荷下ろし場所を固定する必要がない
- 保管スペースを最大限活用できる
- パレットの置き場管理を効率化できる
- 複数台のAGV運用にも対応しやすい

---

## 4. 通路幅2mで1100パレットを通路脇へ荷下ろし

ABMD15の部分的な自律走行機能により、**通路幅2mがあれば1100パレットを通路脇へ荷下ろしする運用**を可能にします。

従来のように、パレットを走行ルート上に配置する必要がないため、限られたスペースでも搬送と保管を両立できます。

### 期待される効果

- 既存レイアウトを大きく変更せずに導入しやすい
- 狭い物流現場でも保管エリアを確保できる
- 通路と保管スペースを効率的に活用できる

---

# 5. 3方向分岐機能

ABMD15では、十字路における3方向分岐に対応します。

従来のABM15では、基本的に2方向の分岐しかできず、十字路での3方向分岐には対応できませんでした。

ABMD15では部分的な自律走行機能を組み合わせることで、

- 左方向
- 直進方向
- 右方向

の3方向へ進むことができます。

### 設置方法

分岐点では、**磁気テープを十字形に貼るだけ**で走行ルートを構成できます。

大規模な設備変更や複雑な機械式分岐装置を必要とせず、比較的簡単にレイアウト変更へ対応できます。

---

# 6. 狭い曲がり角への対応

従来の磁気テープ式AGVでは、自動で曲がることが難しい狭い曲がり角がありました。

ABMD15では、分岐機能と部分的な自律走行を活用することで、これまで対応が難しかった狭い曲がり角でも走行できるようになります。

### 効果

- 複雑な物流ルートに対応
- 既存工場のレイアウトを活用しやすい
- 走行ルートの自由度が向上
- AGV導入可能なエリアを拡大

---

# 7. 磁気テープ＋自律走行のハイブリッド方式

ABMD15は、すべてを自律走行で行うAMRとは異なり、

**「通常走行は磁気テープ」**
+
**「必要な場所だけ自律走行」**

というハイブリッド方式を採用しています。

そのため、AMRのような高い自由度を必要な部分だけに限定し、コストを抑えることができます。

## 価格

- **定価：約600万円**

AMRと比較して導入コストを抑えながら、磁気テープ式AGVの弱点である、

- 荷下ろし場所の制約
- 複雑な分岐への対応
- 狭い場所での走行
- 保管エリアの有効活用

を改善することを目指しています。

---

# 8. フォーク方向へのバック走行時の安全性

ABMD15には、フォーク方向へバックする場合にも安全装置を搭載しています。

通常の走行方向だけでなく、フォーク側へ後退する際にも周囲の安全を確認しながら走行できるようにすることで、物流現場での安全性を向上させます。

### 対象となる場面

- パレット保管エリアへの進入
- 荷下ろし後の後退
- 狭いスペースでの位置調整
- 自律走行エリアから磁気テープ走行への復帰

# ABM15とABMD15の比較

| 項目 | ABM15（従来） | ABMD15（開発機） |
|---|---|---|
| 基本走行 | 磁気テープ | 磁気テープ＋部分的自律走行 |
| 荷下ろし | 磁気テープ上が基本 | 通路脇へ自律走行して荷下ろし |
| 複数パレットの仮置き | 制約あり | 複数パレットをまとめて保管可能 |
| 空きスペースへの荷下ろし | 対応困難 | 空きスペースを探して荷下ろし |
| 3方向分岐 | 非対応 | 対応 |
| 分岐点の施工 | 制約あり | 十字形に磁気テープを貼ることで対応 |
| 狭い曲がり角 | 対応困難 | 分岐・自律走行機能で対応範囲を拡大 |
| 保管エリアの活用 | 走行ルート上に制約 | 通路脇を有効活用 |
| 価格 | 磁気テープ式AGV | 定価約600万円を想定 |
| フォーク方向へのバック | - | 安全装置を搭載 |

# コンセプト

## 必要な場所だけ自律走行

ABMD15の最大の特徴は、すべてをAMR化するのではなく、必要な場所だけ自律走行を行うことです。

> **磁気テープ走行の安定性・低コストと、AMRの柔軟性を組み合わせる。**

これにより、

- 物流現場の既存設備を活用
- 導入コストを抑制
- 保管スペースを有効活用
- 複雑なルートに対応
- 人の作業を効率化

することを目指します。

# 物流展で訴求するポイント

## 「AMRほど高価ではない。でも、磁気テープAGVより自由。」

ABMD15は、磁気テープ式AGVとAMRの中間に位置する新しい搬送機器です。

### 来場者への主な訴求ポイント

1. **磁気テープから外れて通路脇へ荷下ろし**
2. **複数パレットを溜めて、人がまとめて処理**
3. **空きスペースを自動で探して荷下ろし**
4. **通路幅2mで1100パレットの通路脇荷下ろしに対応**
5. **十字路で3方向分岐**
6. **分岐点は磁気テープを十字形に貼るだけ**
7. **狭い曲がり角にも対応可能**
8. **AMRより安価なハイブリッド方式（定価約600万円）**
9. **フォーク方向へのバック走行時も安全装置で安全性を確保**

# まとめ

ABMD15は、従来の磁気テープ式AGVで課題となっていた、

- 荷下ろし場所の制約
- パレット保管スペースの不足
- 複数パレット運用の難しさ
- 複雑な分岐への対応
- 狭い曲がり角での走行

を、**必要な場所だけ自律走行するハイブリッド方式**によって解決することを目指した開発機です。

物流展では、

> **「磁気テープAGVの低コスト」と「AMRの自由度」を両立する新しい搬送機器**

としてABMD15の価値を訴求します。
